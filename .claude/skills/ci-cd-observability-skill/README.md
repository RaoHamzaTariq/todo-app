# CI/CD Observability Skill

This skill provides guidance and tools for implementing continuous integration, deployment, and observability practices for the Todo Chatbot application.

## Purpose
Implement continuous integration, deployment, and observability, including:
- Creating GitHub Actions pipeline for Minikube → Oracle OKE deployment
- Automating Helm chart deployments and environment promotions
- Ensuring monitoring/logging hooks, resource checks, and failure handling
- Collaborating with context-verifier-agent to use latest CI/CD practices

## Key Features
- Complete CI/CD pipeline templates
- Multi-environment deployment strategies
- Monitoring and observability configuration
- Configuration validation tools
- Security scanning integration

## Files Included
- `SKILL.md` - Main skill documentation
- `references/cicd-pipeline-examples.md` - Detailed pipeline configuration examples
- `scripts/validate_cicd_config.py` - Configuration validation tool
- `assets/github-actions-workflow-template.yml` - Complete workflow template

## Usage
Use this skill when implementing or managing CI/CD pipelines for the Todo Chatbot, particularly for automated deployments from Minikube to Oracle OKE and ensuring proper observability practices.
